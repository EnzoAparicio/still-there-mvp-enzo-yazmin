# Still There - MVP

MVP del Reto informático UCU 2026 (Equipo 5, EnYi: Enzo Aparicio y Yazmin Espagnolo), basado en el proyecto *Still There* presentado al NASA Space Apps Challenge 2026 (desafío *Abandoned but not Forgotten*).

## Estructura
```
backend/    API (Node.js + Express + SQLite)
frontend/   pantallas del juego (HTML, CSS, JavaScript, Leaflet)
docs/       documentación
```

## Requisitos
- Node.js 24 (LTS)
